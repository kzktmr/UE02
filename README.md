# 都市経済学【R演習】実証トピックス2

都市経済学の【実証トピックス2】用のリポジトリです。

## 起動方法

下のリンクをクリックしてください。

[![Binder](https://binder.cs.rcos.nii.ac.jp/badge_logo.svg)](https://binder.cs.rcos.nii.ac.jp/v2/gh/kzktmr/UE02/main)

## 含まれるパッケージ

- tidyverse（データ処理・可視化）
- readxl（Excelファイルの読み込み）
- sf（空間情報データの読み込み、操作）
- tmap（地図描画）

## データ

`data/` フォルダに含まれるデータは以下のとおりです。

| ファイル | 内容 |
|---|---|
| `L02-25_17.geojson` | 都道府県地価調査データ（石川県・2025年） |

データの出所：

- [国土数値情報ダウンロードサイト | 都道府県地価調査データ」](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-L02-2025.html)
